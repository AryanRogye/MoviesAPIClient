# MoviesAPICore

`MoviesAPICore` wraps the Kotlin Multiplatform `SharedLogic` framework as a
Swift package binary target. Importing `MoviesAPICore` also makes the public
`SharedLogic` API available.

After cloning the repository, generate the packaged binary from the repository
root before opening the Xcode project:

```sh
./MoviesAPICore/update-shared-logic.sh
```

Run the same command again after changing Kotlin code to regenerate the
XCFramework.

The XCFramework must exist in `Frameworks/SharedLogic.xcframework` before Xcode
resolves the local package, so it cannot be generated by an app build phase.
